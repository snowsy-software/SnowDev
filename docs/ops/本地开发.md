# 本地开发与验证

## 前置条件

- Node.js 20.19.0 或更高版本。
- 推荐 npm 10 或更高版本。
- 使用 `snowdev doctor` 的消费项目还需要 Docker Desktop 或兼容的 Docker Engine 与 Compose plugin。

## 安装与日常检查

```bash
npm install
npm run typecheck
npm run lint
npx prettier --check .
npm test
npm run build
npm run pack:check
```

PowerShell 若因执行策略无法调用 `npm.ps1`，使用 `npm.cmd` 与 `npx.cmd`，例如 `npm.cmd test`。不要为了执行项目命令而降低系统全局执行策略。

## 本地 CLI

```bash
node dist/cli.js --help
node dist/cli.js doctor
```

`doctor` 必须从包含 `snowdev.config.mjs` 的消费项目目录运行。若当前仓库未提供自身配置，报告配置缺失是预期结果，不代表 CLI 损坏。

## 打包检查

`npm run pack:check` 会运行 `npm pack --dry-run`。审阅输出时确认不包含源环境文件、测试 fixture、私有文档或业务 Docker 资产。
