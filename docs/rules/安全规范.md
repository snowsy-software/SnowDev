# 安全规范

## 敏感信息与日志

1. 不提交 `.env`、密钥、token、密码、真实服务地址或客户运行资产。
2. 命令日志必须可复制，但在输出前脱敏 token、password、secret、API key 和 authorization 等值。
3. 错误信息不得输出完整环境变量、秘密内容或未经处理的第三方异常细节。

## 运行安全

1. 禁止 `shell: true`、`exec` 风格字符串命令和由配置直接执行的 shell 片段。
2. 所有破坏性操作必须说明影响范围；非交互环境必须要求 `--yes`。
3. 测试必须使用独立 Compose project、profile 与数据卷，清理不得影响开发数据。
4. `doctor` 只能诊断，不得修改 Docker 状态、文件或环境。

## 发布安全

npm 公共包仅可包含 `dist/`、`src/`、README、LICENSE 和必要模板/类型。发布前必须遵循 [发布门禁](../release-gate.md)，并审阅待发布文件不含秘密、客户数据、内部基础设施或其他不应公开的信息；未经维护者明确授权不得运行发布工作流。
